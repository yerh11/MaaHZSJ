# 《魂坠深境》自动脚本 · 使用文档

**这份是写给"跑脚本的人"的**：怎么起、它自己会做什么、什么时候会停、停了怎么办、
想改规则改哪个文件。至于"脚本内部怎么搭的"（认屏表、四层结构、管线协议），
看工作区根目录的 `CLAUDE.md`，这份不重复。

---

## 一、它现在能干到什么程度

一句话：**从主界面开一局 → 走地图 → 处理沿途每个地点、事件、战斗 → 走到结局
（通关或失败）→ 收尾回主界面 → 再开下一局**，这一整圈不用人点。

边界说清楚：

- **游戏内登录还是手动的**。脚本从"已登录"接手 —— 冷启动能看到标题界面或主界面，
  就算登录好了。
- **没定过策略的分支会主动停车**并说清停在哪（见第五节）。**停车不是故障**，
  是"这儿还没教过脚本"。停车永远停在那儿，不会自己乱撞。
- 通关和失败**都**能自己收尾回主界面；胜负会写进日志（判据是结算屏左上角那行标题）。

## 三、怎么跑

```bash
cd MaaHZSJ
export PYTHONIOENCODING=utf-8        # Windows 下必须，否则中文日志会炸
python script/battle.py 噩梦9层
```

- **难度**（缺省 `噩梦9层`）：`普通` / `困难` / `险恶` / `严酷` / `极难` /
  `噩梦1层` ~ `噩梦9层`
- **启动时游戏停在哪都行**（不用先摆好）：
  - 停在**局内**（战斗/地图/某个地点）→ **接着这一局走完**。不重启、不另开一局、
    也不动这一局开局时定的难度；
  - 停在**局外**（主界面/标题界面/公告页）→ 回主界面，开新局。
- **一局正常收尾会自动开下一局**，一直跑。**停只有两种**：手动 `Ctrl-C`，
  或者"这一局没正常收尾"（停车等人 / 未知界面 / 达到步数上限 / 战斗超时之后
  **连"退出这一局"都走不通**）—— 后者必须有人来看，所以脚本会停住，
  不接着开新局把现场盖掉。
- **一把战斗打超过 5 分钟**不属于上面那种"出事"：脚本会**退出这一局**（放弃），
  收尾回主界面，然后接着开下一局。被放弃的这局**不记胜负**（它不是打通的，
  也不是打输的）。
- 想挂后台跑（推荐，日志落盘）：

  ```bash
  python -u script/battle.py 噩梦9层 > debug/run_$(date +%m%d_%H%M).log 2>&1 &
  ```

- **只想跑一局**，或者接着当前这一局跑（不回主界面、不开新局、不重启）：

  ```bash
  python debug/play.py          # 接着跑
  python debug/play.py 40       # 最多跑 40 步（默认 400）
  ```

## 四、脚本自己会做哪些决定（已经定过的）

这些**不用问人**，脚本直接做完。要改哪一条见第七节。

| 场景 | 脚本怎么做 |
|---|---|
| 开局 | 主界面 →「启动祭坛」→ 难度轮盘选档 →「坠入深境」 |
| 地图选路 | **按优先表自动选**（表在 `script/nav/map.py` 的 `NODE_PRIORITY`，数字小的先去；同一档取先读到的那个） |
| 地图·只有一条路 | 不管优先表，**直接走**（保底一） |
| 地图·读不到可前往 | 先点掉挡视线的残余信息框，再上/左/右/下**各拖一次屏幕**重读（保底二）；四边都读完还是空才停车 |
| 地图·走一步没走成 | **重读地图、重新按优先级挑一条再走**，最多 3 次（保底三，2026-10-03 加）。治的是"读到的位置是歪的"（现场那次读数比真位置低了 64px，命令它去点时它按位置找不到那个节点，一个点击都没发就停车）。三次都走不成才停车 |
| 篝火 | 魂晶够 3 就先「激活护符」（进护符选择界面）；点不动就「坐下休息」（满血不试）；再不行「离开地点」。**三种都不算异常** |
| 护符选择界面 | 按框上**印的号** 1→2→3→4→5 依次点，谁弹出详情面板就激活谁（花 3 魂晶） |
| 已激活护符屏（「选择1个已激活护符，…」，事件「狭缝」选“坠入”之后有时先落这一屏） | **两段式**：① **点最上面那一行**（用户 2026-10-04：「选择第一个护符」；两版卷面「…使其施放冷却-1（最低为1。）」/「…复制其当前状态。」都是这一条）—— 行位置固定、量出来的（第一行名字框 `(110,371,88,24)`，行距 95）；② 这一行点亮后会浮出一张详情卡 + 一枚 **「确认选择」**（量到浮在 `(637,398,81,22)`，score 1.0000），**再点它这一屏才走**（跟这游戏别处的选项一个规矩：光点选项是"高亮"，不算数）。⚠️ 头一版只做了第 ① 步，2026-10-05 实机证伪、当场停车。**接着那一页还没量过**，交给主循环认（认不出就存图停车）。⚠️ 这一屏从前被末尾那行「通用离开屏」按「离开地点」抢走 ⇒ **首领战丢了**，这就是用户报的「不会选择第二个选项，直接面对首领」 |
| 印记石 / 祝福祭坛 | **不碰可选的那一项**（将手放入凹槽 / 触摸祭坛），直接离开 |
| 商店（神秘商人） | 点「移除卡牌」，把非保留卡（无畏斧 / 莽撞头槌 / 隐痛 之外的）**一张一张销毁**：点「移除卡牌」→ 弹出**销毁卡牌屏**（标题「你的卡组」）→ 销毁一张 → 面板自己收掉、又站回商店屏 → 再点，直到**没有可销毁的**或**点着了却进不去面板（金币不足）** —— 那时点「离开地点」走人。保留名单是 `script/shared/cards.py` 的 `KEEP`（名字）+ `KEEP_TEMPLATES`（卡面，**两份必须一起改**；事件那条移除屏共用同一份名单）。**「购买卡牌」不点**（还没定过策略） |
| 销毁卡牌屏（商店点「移除卡牌」之后弹出那屏） | **卡面先筛、名字后验**：四条卡面模板（`assets/resource/pipeline/卡面.json`）认出保留名单里的格子 → 不碰；剩下的格子按行优先点开读卡名，名字在名单里 → 以名字为准、换下一格；名字读不出来 → **停车**。挑中之后读屏上那行「支付 N金币」的价钱，金币不够就走人（用户 2026-10-04：「金币不足时或没有可移除时离开」）。销毁一张之后**面板留在原地**（实测），脚本接着清下一张；每次点完「销毁」都**等屏上真少一张**（实测约 0.5s，牌要烧一下），下一轮读网格前也先**等它别再动**（牌在挪位时读到的是过期位置）。两个出口都点左上角返回箭头退回商店屏，由商店点「离开地点」 |
| 选卡屏（标题「选择卡牌」，事件里弹出来的那屏） | **两版移除屏 + 复制屏 + 升级屏，靠副标题分派**：① 副标题「从卡组中选择一张卡牌移除。」→ 扫一遍卡组挑一张不在保留名单里的移除，一张可移除的都没有 → 点左上角「返回」取消；② 副标题「选择最多3张卡牌，将其移除。」（2026-10-04 事件「狭缝」第一次撞上，**这一版没有「返回」**，出口只有底下那枚「确定」）→ 点一张＝**加进选中**、最多 3 张，名单里的牌点开看清名字后当场取消（**点开读名要连点两下**：这一下选中、下一下点回去，净效果为零），选完点「确定」踩实；**一张可移除的都没有也点「确定」走人**（用户 2026-10-04：「可以不选择」）。⚠️ 这一屏**灰罩只在选满 3 张时才出现**，所以"选着 1~2 张"是看不出是哪几张的 —— 进门撞上这种就停车（`cardpick_preselected`），不猜；③ **复制屏**（2026-10-06 并成一条路）→ 按默认取左上角第一张，读都不读卡名 —— 用户 2026-10-02 定的是「默认第一张」，2026-10-06 又明确「如果触发了选卡, 默认选第一张」，**两副卷面（副标题读不到的那版 / 写着「选择1张卡牌，复制2张加入牌组。」的那版）动作一模一样**，从前那条"挨格点开读卡名、读到「莽撞头槌」才选它"（`_copy_named` / `COPY_CARD`）整个删了；④ 副标题里带「升级」→ **升级屏**（「选择最多3张可升级卡牌，将其升级。」，2026-10-04 事件「狭缝」→ 第 2 格「“坠入”」之后撞上，是这个入口的第二个落点）→ **一张都不选、一格都不碰，直接点「确定」**（用户 2026-10-04：「一张都不选，直接「确定」」+「照「可以不选」先办」）；这一屏的牌是**居中排**的（存档帧上 2 张，列心 868/985、行心 221），与写死的 5 列格子不是一张表，而这一趟本来也不需要格子。前两版（两版移除屏）都**读不出卡名就停车**（分不清是不是名单里的牌）；后两版（复制屏、升级屏）**压根不读卡名** |
| 献祭锻造间 | 进去看一眼：有没升变过的斧头就升（一把 6 金币，能升几把升几把），然后返回、离开 |
| 始源之凝视（开局赐福三选一） | 三张里有**「宝石收集者」就接受它**（认的是**卡名那一行**，`宝石收集者-左/中/右` 三个窄 roi 节点）；**没有就点下方右边那颗「刷新」—— 只点这一次**（右边那颗当场写 `刷新(0/1)`，**左边那颗一下都不点**）。刷过这一次：出了就接受；还是没有（或点了卡面不动）→ **一张都不拿、直接点「离开地点」**。用户 2026-10-06 定，取代 2026-10-01 的「不拿、直接离开」，也取代同一天早些时候那句「换到出为止」（`刷新(N/M)` 的 N 是**已用**次数，两颗加起来只够 4 次，12:13 实撞五批 15 张都没出）。接受完这一屏**多半还要点「离开地点」**才进第一层（看结果：屏走了就不点）；一张都不拿时「当前未获取始源祝福，是否离开？」那个确认框会弹 |
| 路口（地图「深入」之后那屏） | 一律走**第 1 条**道 |
| 游艺（转盘 / 移形变位 / 最佳轮换 / 大转盘） | 一律**拒绝并触发战斗** |
| 战斗 | 只点「自动出牌」，让游戏自己打完。弹出模态框时按定过的策略点：同化 →「确定」；夜巡人 → 第 1 项；贪婪之怒 → 第 2 项「护甲牌」；最后的机会 →「挣扎」；黑市行医 → 丢弃**最右**那张牌；敌方「选择敌方卡组中的1张牌移除」→ 选第一张（2026-10-07）；死亡 → 点一下屏幕 →「不留下遗物」 |
| 战斗·按钮点不动 | 右边上下两枚**都**写着「结束回合」。上面那枚（自动出牌）被游戏画成灰匾、点它回合数不动时，改点**下面**那枚（手动结束回合）：连着 4 次读出同一个「第N回合」、且拖过 20 秒才算（尺子是游戏自己那行回合数；判据与来历见 `script/core/auto.py` 的 `AUTO_STUCK_CLICKS`） |
| 战斗·超过 5 分钟 | **退出这一局**（卡牌菜单 → 设置 →「放弃此轮游戏」）→ 收尾回主界面 → 接着开下一局。这一局**不记胜负**。5 分钟这个数是 `script/combat/fight.py` 的 `BATTLE_LIMIT`（用户 2026-10-03：「在一把战斗超过5min后,则直接退出该局」）；"退出后接着开下一局"也是那天定的 |
| 战斗奖励 | **什么都不拿**，直接离开 |
| 事件 | 按 `script/events.json` 里那一条的 `pick` 走；那一格**点不动**时若有 `fallback`，就改选退路那一格（见第七节，「真龙现身」那条）。**没记录过的**事件自动入册（选项原文存下来）+ **停车问人** |
| 单选项屏（屏上只有一个选项、又没有离开按键） | **双击**那一行（保底三） |
| 一局结束 | 结算屏读胜负（「仪式终结?」= 通关 /「仪式失败」= 没通关 / 都没读到 = 如实记"没读出来"）→ 收尾回主界面 → 开下一局 |

## 五、什么时候会停，停了怎么办

停车 = 脚本停下了，理由要么是"这儿没定过策略"，要么是"没读明白"。**每次停车都会
存一张现场图**到 `debug/screenshots/`（图名见下表），那是定策略的唯一凭据。

| 日志里的理由 | 意思 | 你该做什么 |
|---|---|---|
| `等待事件` / `等待事件（未定策略）` | 撞上没见过的事件，或者事件集里这条 `pick` 还是 `null`；或者 `pick`（连同 `fallback`）那一格**点不动**（现场图 `event_park_<事件名>_noclick.png`；`fallback` 写歪了则是 `_badfallback`） | 看 `events.json` 里那条的选项 + 现场图 `event_new_<事件名>.png`，把该选哪项告诉我 |
| `等待选路` | 地图上读不到可前往节点、那个词条优先表里没定过，或者**连走 3 次都没走成**（每次都重读过、重挑过） | 看现场图 `map_goto_fail.png` / `battle_map.png`，告诉我这个词条排哪儿 |
| `等待选卡` / `等待选卡（确定没点掉）` | 选卡屏上某个判据不成立，**现场图名就写着是哪一件**：`cardpick_nogrid`（一格都没读出来 / 格子读花了，牌不是从左上角起排满的）、`cardpick_wash_mismatch`（**屏上有灰罩、可亮着的不是 3 格** —— 「有灰罩」与「亮着 3 张」本该是同一件事，对不上就是这一帧读花了，不点）、`cardpick_name_unknown`（点开那一格读不出卡名 —— 可能是这一下点漏了（会重点一次），也可能真是张名字认不出的牌；两种情况都分不清是不是保留名单里的牌）、`cardpick_preselected`（**进门时面板弹着、却没有灰罩** —— 那是「选着 1~2 张」的样子，可这一屏只有选满 3 张才看得出选中的是哪几张，看不出就不动手）、`cardpick_undeselect`（想取消选中，可点了它还在选中里 / 面板不收回）、`cardpick_pick_mismatch`（**打算选的与屏上选的对不上** —— 对不上就不点「确定」）、`cardpick_noconfirm`（「确定」点不着/点了没反应）、`cardpick_noback` / `cardpick_back_stuck`（第一版那个「返回」）、`cardpick_unknown_effect`（副标题读到了、却不在上面那四版里）、`cardpick_upgrade_noconfirm` / `cardpick_upgrade_stuck`（升级屏上「确定」点不着／点了这屏不走 —— 那一屏**没选任何牌**时点它算不算数没量过，不猜） | 发我现场图 + 日志 |
| `等待选护符` | 5 个候选挨个点过都没弹面板，或者「激活」之后屏还在（多半是护符替换确认框盖着，那个框的是/否还没定过） | 同上 |
| `等待选护符（已激活护符那一屏）` | 「选择1个已激活护符，…」那一屏上的三个出口：`amulet_pick_noclick`（这一屏的标志物没认住，那一记**一下都没发出去**）、`amulet_pick_noconfirm`（第一行点下去了、可「确认选择」没浮出来）、`amulet_pick_stuck`（第一行＋「确认选择」都点了、可这屏还挂着 —— **不补第三下**） | 发我现场图 + 日志 |
| `等待选路口` / `等待游艺` / `等待锻造` / `等待篝火` / `等待卡牌展示` | 各屏自己的异常出口（读不出选项、面板没画上来、按钮点不动……） | 同上 |
| `等待离开（××）` | 某个地点或弹窗的「离开地点」点不掉。括号里是哪个：通用 / 祭坛 / 确认弹窗 / 战斗结算 / 怪石造物 / 始源之凝视 / 化形信使 | 同上 |
| `等待接受（始源之凝视）` / `等待刷新（始源之凝视）` / `等待离开（始源之凝视）` | 开局赐福那屏（2026-10-06 起要挑「宝石收集者」了、且**只按右边那颗「刷新」一次**）的四个异常出口：**现场图名就写着是哪一件** —— `gaze_accept_stuck`（认出了「宝石收集者」、可它那一格的「接受」点不着）、`gaze_refresh_noclick`（三张里没有它、该按右边那颗「刷新」了，可这一下没点出去）、`gaze_stuck`（接受完要走了，可「离开地点」点不着）、`gaze_leave_stuck`（刷过一次还是没有、该走了，可「离开地点」点不着） | 发我现场图 |
| `等待商店` | 商店屏上那两件事之一没走通，**现场图名就写着是哪一件**：`shop_remove_noclick`（「移除卡牌」认不出/点不着）、`shop_leave_stuck`（该走了，可「离开地点」点不动） | 发我现场图 |

## 七、想改一条规则

- **事件选哪一项**：改 `script/events.json` 里那条的 `pick`：
  - `0` = 第 1 项，`1` = 第 2 项 ……（**从 0 起算**）
  - `"leave"` = 这一屏什么都不选，走「离开地点」
  - `null` = 策略还没定，**遇到就停车问人**
  - 可选：再加一条 `"fallback"`（同样从 0 起算）= **`pick` 那一格点不动时改选哪一格**。
    用途见「真龙现身」：第 2 格「献上金币」要 15 金币，付不起时游戏根本不理这一下
    （2026-10-05 现场：手里 10 金币、点了两轮都没选中）—— 用户当天定「金币不够就改选
    第 1 格『揭穿他』」⇒ `"fallback": 0`。**退路也是写死的一格**，不是"随便再试一个"；
    两格都点不动就照旧停车。没用这个字段的事件，行为跟从前一样。
  - 可选：再加一条 `"tap"` = 这一屏的选项格**单击还是双击**：不写 = `"double"`
    （缺省，双击），写 `"single"` = 只单击、不点第二下。现在只有「游艺」写 `single`
    （翻牌时第二下会落到下一屏的牌桌上）。写别的值 = **一格都不点、停车**。
    ⚠️ "第二段确认"（浮出「确认选择」/ 同一格再点一下）**不记在这里**，脚本当场认。

  这个文件**每次遇到现读**，改完**不用重启脚本**，下一次撞上就按新的走。
- **地图优先级**：`script/nav/map.py` 的 `NODE_PRIORITY`（数字小的先去）。
- **别的**（某个屏某一步怎么走）：在 `script/nodes/`（地点）/ `nav/`（寻路）/
  `combat/`（战斗）/ `system/`（界面）里找到那一屏的模块，改它的 `handle()`。
  目录怎么分、每层能依赖谁见 `docs/zh_cn/架构与流程图.md`。
  改完请跑一遍第八节那套自检。
- 写 JSON 的注意：`assets/**/*.json` 按 **JSONC** 处理，可以写 `//` 注释，
  缩进统一 4 空格。
